# Транслятор конфигураций — вариант №23

Программа читает учебный конфигурационный язык из файла и выводит JSON
в стандартный поток вывода. Грамматика описана в `src/config.lark`,
а синтаксический разбор выполняет Lark.

## Установка и запуск

Требуется Python 3.8 или новее. Команды выполняются из папки
`config-translator`. Отдельный шаг сборки не требуется.

```powershell
python -m pip install -r requirements.txt
.\run.bat --input examples/data-center.conf
python -X utf8 src/main.py -i examples/museum.conf
```

На Linux и macOS используйте `python3` и
`./run.sh --input examples/data-center.conf`.

| Ключ | Назначение |
| --- | --- |
| `-i PATH`, `--input PATH` | Обязательный путь к входному файлу UTF-8. |
| `-h`, `--help` | Справка по параметрам. |

При успехе программа завершится с кодом 0. Ошибки чтения и трансляции
пишутся в stderr и завершают программу с кодом 1. Ошибки параметров
командной строки обрабатывает argparse с кодом 2.

## Синтаксис

- `%{ ... %}` — многострочный комментарий.
- `42`, `+42`, `-42` — целые числа.
- `'текст'` — строка в одинарных кавычках на одной строке.
- `begin имя := значение; end` — словарь. Пустые и вложенные словари
  допустимы. Имена ключей и констант состоят из латинских букв и `_`.
- `значение -> имя` — объявление константы перед итоговым значением.
- `![имя]` — ссылка на ранее объявленную константу в позиции значения.

Файл содержит произвольное число объявлений и одно итоговое значение.
При трансляции объявления вычисляются слева направо, а в JSON попадает
итоговое значение. Неизвестные константы, повторные объявления и
повторные ключи одного словаря считаются ошибками.

## Примеры

`examples/data-center.conf` описывает сетевой шлюз центра обработки данных.

```json
{
  "location": "Москва",
  "gateway": {"protocol": "https", "listen": 443}
}
```

`examples/museum.conf` описывает экскурсию и гардероб музея.

```json
{
  "title": "Музей космонавтики",
  "guided_tour": {"language": "русский", "capacity": 20},
  "coat_check": {"floor": -1}
}
```
