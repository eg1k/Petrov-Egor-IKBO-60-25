# Эмулятор языка оболочки ОС (вариант 23)

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом на Python (tkinter).

## Этап 1. REPL

Реализовано:

- графический интерфейс (окно с областью вывода и строкой ввода);
- заголовок окна формируется из реальных данных ОС: `Эмулятор - [username@hostname]`;
- парсер с поддержкой кавычек (`'...'`, `"..."`) и раскрытием переменных окружения реальной ОС (`$HOME`, `${USERNAME}`);
- команды-заглушки `ls` и `cd`, выводящие своё имя и аргументы;
- команда `exit` (с необязательным числовым кодом);
- обработка ошибок: неизвестная команда, незакрытые кавычки, неверная подстановка `${...}`, неверные аргументы `exit`.

## Этап 2. Конфигурация

Реализовано:

- параметры командной строки:
  - `--vfs ПУТЬ` — путь к физическому расположению VFS;
  - `--script ПУТЬ` — путь к стартовому скрипту;
- отладочный вывод всех заданных параметров при запуске эмулятора;
- стартовый скрипт: команды выполняются последовательно, на экране отображаются
  и ввод, и вывод (как в диалоге с пользователем); строки с ошибками пропускаются,
  пустые строки и комментарии (`#`) не выполняются;
- стартовые скрипты эмулятора в папке `scripts/`;
- скрипты Windows в папке `tests/` для проверки всех параметров командной строки:

| Скрипт | Что проверяет |
| --- | --- |
| `test_no_args.bat` | запуск без параметров |
| `test_vfs.bat` | задан только `--vfs` |
| `test_script.bat` | задан только `--script` (полный демонстрационный скрипт) |
| `test_all_params.bat` | заданы оба параметра |
| `test_missing_script.bat` | стартовый скрипт не существует |
| `test_bad_args.bat` | неизвестный параметр |
| `test_help.bat` | справка `--help` |

Интерпретатор Python для тестов можно задать переменной окружения `PYTHON`.

## Этап 3. VFS

Реализовано (модуль `vfs.py`):

- источник VFS — ZIP-архив, заданный параметром `--vfs`; архив только читается,
  на диск ничего не распаковывается, все операции выполняются в памяти;
- содержимое текстовых файлов хранится в памяти как строка, двоичных — в base64;
- при запуске выводится содержимое загруженной VFS (строки `[vfs]`);
- ошибки загрузки (файл не найден, не ZIP-архив, каталог) выводятся в окне,
  эмулятор продолжает работу с пустой VFS;
- команда `vfs-save ПУТЬ` сохраняет текущее состояние VFS на диск в формате ZIP.

Тестовые архивы в папке `vfs/` создаются скриптом `python tools/make_vfs.py`:

| Архив | Содержимое |
| --- | --- |
| `minimal.zip` | минимальная VFS: один файл |
| `several.zip` | несколько файлов, в том числе двоичный `logo.png` |
| `deep.zip` | не менее 3 уровней файлов и папок, пустой каталог |
| `broken.zip` | файл, который не является ZIP-архивом |

Скрипты Windows для проверки разных вариантов VFS:

| Скрипт | Что проверяет |
| --- | --- |
| `test_vfs_minimal.bat` | минимальная VFS + `vfs-save` |
| `test_vfs_several.bat` | VFS из нескольких файлов + `vfs-save` |
| `test_vfs_deep.bat` | VFS из нескольких уровней + `vfs-save` |
| `test_vfs_missing.bat` | архив не существует |
| `test_vfs_broken.bat` | файл не является ZIP-архивом |
| `test_full.bat` | стартовый скрипт `scripts/startup.txt` со всеми командами этапов 1–3, включая ошибки |

## Запуск

```
python emulator.py [--vfs ПУТЬ] [--script ПУТЬ]
```

## Пример работы

```
user@host:~$ ls -l /tmp
Команда: ls, аргументы: ['-l', '/tmp']
user@host:~$ cd $USERPROFILE
Команда: cd, аргументы: ['C:\\Users\\user']
user@host:~$ ls "$USERNAME docs" '$HOME'
Команда: ls, аргументы: ['user docs', '$HOME']
user@host:~$ pwd
pwd: команда не найдена
user@host:~$ ls "abc
Ошибка синтаксиса: незакрытая двойная кавычка
user@host:~$ cd ${1abc}
Ошибка синтаксиса: ${1abc}: неверная подстановка
user@host:~$ exit abc
exit: abc: требуется числовой аргумент
user@host:~$ exit
```
